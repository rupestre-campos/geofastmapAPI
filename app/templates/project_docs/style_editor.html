Style editor

The style editor lets you preview and build MapLibre-compatible paint rules for layers and save them as styles.

What you can do

  • Add collections to the map (static tiles if available; otherwise a sample of features).
  • Edit fill/line/point styling and create attribute-based rules.
  • Load styles (public styles + styles saved for collections).

Anonymous vs logged-in

  • Anonymous users can experiment but can’t save styles.
  • Visibility/sharing controls are hidden for anonymous users.

Advanced styling rules

  • Zoom-based styling uses top-level interpolate/step expressions (MapLibre validation requirement).
  • Attribute-based rules are applied via case expressions layered into zoom stops when needed.
