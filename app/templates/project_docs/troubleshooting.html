Troubleshooting

“Job not found” (404) when opening a job

  • Non-admin users can only see jobs they own.
  • If a job was created with owner_id = NULL, it may appear admin-only.
  • Fix: ensure job creation paths pass owner_id (especially worker-created follow-up jobs like post-import tile builds).

Jobs stuck in “pending”

  • Worker process is down or not consuming the queue.
  • Redis connection issues or misconfiguration.

Style editor: layer appears but console shows MapLibre expression errors

  • MapLibre requires ["zoom"] to be input to a top-level step/interpolate.
  • Fix: keep zoom expressions top-level and apply attribute rules inside zoom-stop values.

Slow dynamic tiles

  • Check for unbounded filters or expensive full-text searches.
  • Prefer bbox + selective filters; add indexes where appropriate.
  • Consider switching to static tiles for heavy browse use.
