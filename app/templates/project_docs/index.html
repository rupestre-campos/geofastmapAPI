What is GeoFastMap?

GeoFastMap is an OGC API - Features server with extra tooling for fast browsing and styling: collections, item search, dynamic vector tiles, optional static (prebuilt) tiles, styles, maps, and job tracking.

How to read these docs

  • API docs live at /docs (auto-generated OpenAPI).
  • Project docs (this section) explain how things work, limitations, and operational guidance.
  • These pages are HTML-only and are not listed in OpenAPI, by design.

Architecture (high level)

  • FastAPI serves both JSON endpoints and HTML pages (Jinja templates).
  • PostgreSQL/PostGIS stores feature geometry + properties and most metadata (collections, maps, styles, shares).
  • Redis powers worker queues and job metadata when configured (recommended for production).
  • MapLibre GL JS renders vector tiles and applies styles in the browser.

Core concepts

  • Collection: a dataset/layer identified by collection_id.
  • Item/feature: one row with geometry + properties inside a collection.
  • Style: a paint “spec” used by the style editor (plus advanced rules and zoom stops).
  • Map: a saved composition referencing collections and styles.
  • Job: asynchronous work (imports, tile builds, processing).

Core building blocks

  • FastAPI + Jinja templates: API + HTML UI pages.
  • PostgreSQL/PostGIS: features and metadata storage; features are partitioned by collection_id.
  • Redis: queues + job store (and some caching).
  • MapLibre GL JS: rendering in the browser (style editor, map viewer).

What we optimize for

  • Fast browsing of large datasets via vector tiles.
  • Predictable performance by pushing expensive work to background jobs when possible (static tiles).
  • Simple sharing model: owner + visibility + explicit editor/viewer shares.

Common limits / footguns

  • Dynamic tiles can overload the DB if users do unbounded filtering or expensive searches.
  • Static tiles need rebuilds after large data updates.
  • Very large properties payloads inflate tile size (prefer attribute include/exclude).
