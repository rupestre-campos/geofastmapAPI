What is GeoFast?

GeoFast is an OGC API - Features server with extra tooling for fast browsing and styling: collections, item search, dynamic vector tiles, optional static (prebuilt) tiles, styles, maps, and job tracking.

How to read these docs

  • API docs live at /docs (auto-generated OpenAPI).
  • Project docs (this section) explain how things work, limitations, and operational guidance.
  • These pages are HTML-only and are not listed in OpenAPI, by design.

Core building blocks

  • FastAPI + Jinja templates: API + HTML UI pages.
  • PostgreSQL/PostGIS: features and metadata storage; features are partitioned by collection_id.
  • Redis: queues + job store (and some caching).
  • MapLibre GL JS: rendering in the browser (style editor, map viewer).
