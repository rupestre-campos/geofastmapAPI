Basemaps

Basemaps are background tile sources (raster or vector) used in the UI for context (OSM, satellite, etc.). GeoFastMap manages a basemap catalog and exposes it to the frontend.

What a basemap definition includes

  • Name and optional attribution/labels.
  • Tile URLs and zoom range.
  • Optional API keys depending on the provider.

Operational notes

  • Basemap providers have rate limits and usage policies—ensure you comply.
  • For production, prefer stable providers and cache where allowed.
