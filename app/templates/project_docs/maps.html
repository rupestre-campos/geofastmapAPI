Maps

A “map” is a saved composition: it references one or more collections (layers) plus styling choices. Maps are stored in the database and can be shared similarly to collections.

What a map contains

  • Name/description: human metadata.
  • Definition JSON: layer ordering and configuration (collection ids, styles, etc.).
  • Visibility: private/logged/public.
  • viewer_can_edit: when enabled, any user who can see the map can edit it (use with care).

Performance notes

  • Map performance depends on the underlying collections’ tiles (static recommended for heavy use).
  • Keep the number of visible layers reasonable on initial load.
