Authentication & permissions

GeoFastMap supports HTML sessions for UI pages and HTTP Basic for API clients. Authorization is applied consistently across collections, maps, styles, and jobs.

Authentication modes

  • Session (HTML): login sets a session cookie and UI pages use it to render logged-in state.
  • HTTP Basic (API): API clients can send Authorization: Basic ....

Desktop GIS: QGIS and ArcGIS Pro can use the same API with anonymous access or Basic auth — see QGIS & ArcGIS (OGC API).

Visibility model

  • private: only owner + explicit shares.
  • logged: any authenticated user can see.
  • public: anyone can see.

Sharing

  • Shares are stored in resource_shares with a role: viewer or editor.
  • Editors can modify the resource; viewers can only see it.
  • Admins are special: they can see and manage everything (and are intentionally excluded from editor lists in the UI).

Jobs ownership

  • Jobs are filtered by owner_id for non-admin users.
  • Jobs with owner_id = NULL are treated as admin-only to avoid leaking legacy jobs.

Security notes

  • Login has basic brute-force protection (rate limiting by IP).
  • Public endpoints should be evaluated for performance impact (especially dynamic tiles).
