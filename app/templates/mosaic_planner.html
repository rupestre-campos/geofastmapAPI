Planner picks a sliding 7-day UTC window (e.g. anchor ±3 days so a Sunday scene can pair with Saturday and Monday—not fixed to Mon–Sun ISO weeks). Windows are scored by mean cloud; all strips use only scenes in that window. Each vertical column still prefers one calendar day; another column can use a different day inside the window. Cloud % is not sent to STAC; leftover gaps may still be filled from the pool.
